# Dựng Video

App chỉnh video & ảnh miễn phí (kiểu CapCut / Hypic / PicsArt).

- `android/` – dự án Android Studio → tệp `.apk`
- `windows/` – dự án Electron → tệp `.exe`
- `web/` – bản dùng online: https://ducbui2k5-hash.github.io/dung-video/

Mỗi lần đẩy code lên, GitHub Actions tự build. Tải tệp cài đặt trong tab **Actions → lần chạy mới nhất → Artifacts**.
